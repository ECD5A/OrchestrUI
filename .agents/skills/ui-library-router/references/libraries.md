# Ecosystem reference

Verified 2026-08-20. Re-check official upstream before changing install or licensing facts.

- **Kokonut UI:** polished React/shadcn components. Public registry: `https://kokonutui.com/r/registry.json`; Pro is separate.
- **React Bits:** creative text/background/canvas effects. Public registry: `https://reactbits.dev/r/registry.json`. The free repository is MIT plus Commons Clause; retrieve from upstream and never redistribute its component collection from OrchestrUI.
- **daisyUI:** semantic Tailwind component base and themes. Current docs target Tailwind CSS v4; do not add it as an accidental second base system.
- **Bklit UI:** default chart/analytics specialist. Public index: `https://bklit.com/r/registry.json`; component URLs use the documented `https://ui.bklit.com/r/{name}.json` namespace.
- **Anime.js:** bespoke timeline/SVG/scroll engine, not a dependency for trivial motion.
- **Rive:** interactive vector/state-machine runtime. Runtime code and individual `.riv` artwork have separate rights; record the asset source and permitted use.
- **Magic UI:** animated marketing components and accents. Public registry: `https://magicui.design/r/registry.json`; Pro templates remain out of scope.
